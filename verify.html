Batch Verification

Enter the batch code printed on the package to retrieve product, line and protocol version. The result returns batch registration data; test items and figures follow the accompanying test report.

Enter batch code

Example codes: SW-2026-0001 (seedling board), SW-2026-0002 (growing slab).

Batch code rules and notes

  • Format is SW-YYYY-NNNN, e.g. SW-2026-0001.
  • The code is printed on every bag or pallet label and matches the dispatch note.
  • Results include product, production date, line and protocol version.
  • A miss does not imply counterfeit: a new batch may not be synced yet. Email us with your purchase record for manual verification.
